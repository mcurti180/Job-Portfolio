## Community Pantry Mobile App *(In Development)*

The **Community Pantry App** is a mobile application built using **React Native** with a **Python-based backend** and integrated **database support**.  
It’s designed to help people share food and goods within their local communities. Users can post available items, search nearby listings, and connect through a **real-time chat feature**.

### Key Features
- User authentication and profile management  
- Firestore or SQL-based data storage for posts and user data  
- Geolocation and map-based item search  
- Real-time chat and messaging  
- Responsive React Native interface built for Android and iOS  

This project is currently **under active development** and continues to evolve as new features and backend integrations are added.

## SQL Mini Store Database Project

The **SQL Mini Store Project** is a database-driven system designed to simulate an **online retail store**.  
It demonstrates my understanding of **SQL queries, data relationships, and schema design**, including product tables, user accounts, order tracking, and inventory management.

### Highlights
- Structured relational database design (tables for customers, products, and transactions)  
- Query optimization, joins, and data retrieval  
- Implementation of CRUD operations and sample reports  
- Demonstrates back-end integration skills using Python and SQL
